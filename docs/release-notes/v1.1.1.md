# ADDGP-Lite 1.1.1

**A privacy fix release. Use this instead of 1.1.0, which was never published.**

Everything in [1.1.0](v1.1.0.md) — the local browser UI, `addgp-lite ui` — plus three fixes
found while writing [the data privacy and governance document](../DATA_PRIVACY_AND_GOVERNANCE.md).
All three affect only full scans, which call AI models. Local-only use is unaffected.

## Fixed

- **The quote check could fetch any URL.** Phase 2 downloaded whatever page a model cited,
  outside the egress gate, so a made-up or injected citation could have made the tool
  request an internal address on the user's network. It now fetches only https pages on the
  region's official authority domains or a recognised legal publisher, follows at most one
  redirect to another allowed host, never runs in `--offline`, and records every fetch in the
  egress ledger. Earlier documentation saying "only openrouter.ai is ever contacted" was
  wrong for this request and has been corrected.
- **Real file paths were sent in the local-findings summary** to phases 1, 4 and 5. They are
  now placeholders, like the paths in the code itself.
- **Real names could be sent a second time.** Model answers have real names restored as soon
  as they arrive. When an answer was fed into a later phase, those names went out with it.
  They are now turned back into placeholders before sending.

If you ran a full scan with an earlier version, `.addgp/egress.jsonl` lists every outbound
request it made and which files each one covered.

## New

- [`docs/DATA_PRIVACY_AND_GOVERNANCE.md`](../DATA_PRIVACY_AND_GOVERNANCE.md): for a security
  or data-protection lead. What runs offline, every outbound request, what the models see,
  how findings are checked, and the limits, each tied to a file, test or command.

## Verify what you were handed

```bash
shasum -a 256 -c SHA256SUMS
```

The binaries are still unsigned, so Windows SmartScreen or Defender may flag the `.exe`. See
the [v1.0.0 notes](v1.0.0.md#known-gaps).

## Known gaps

- The model-facing phases have been run live once, by the maintainer. No recorded test runs
  or measured costs are in the repository. Treat their output as unreviewed.
- No pattern for the UAE Emirates ID number yet.
- The plain-English project description is sent to the model as written, not pseudonymised.
- Unsigned binaries.

148 tests pass.
