# ADDGP-Lite 1.1.0

**New: `addgp-lite ui` — the same tool, in your browser, still entirely on your machine.**

```bash
addgp-lite ui
```

It opens a local page with five views:

- **Overview** — gap counts by severity, last scan, spend, and how many bytes have ever left
  this machine (and to where).
- **Gaps** — filter by severity or text, read each gap's What / Why / How / Consequence and its
  citations, and copy the agent prompt with one key. `j`/`k` to move, `c` to copy, `/` to filter.
- **Local findings** — the free, offline evidence scan. Works before you have a key.
- **What leaves** — per file, exactly what the redactor would send, and what is refused outright.
- **Egress ledger** — every outbound call this project has ever made.

## What it does not do

The UI keeps every promise the CLI makes, and is tested for each:

- Served from the binary on `127.0.0.1` only. Nothing is hosted; there is no account.
- Read-only. It never calls a model and never writes to your project.
- Loads nothing from the internet — no CDN, no web fonts, no scripts — so it works offline
  and cannot phone home.
- The printed link carries a one-time token. Other websites cannot read the page's data (no
  CORS grant, and requests with a foreign `Host` header are refused), and neither can other
  users on the machine who don't have the link.

## Verify what you were handed

```bash
shasum -a 256 -c SHA256SUMS
```

The binaries are still unsigned, so Windows SmartScreen or Defender may flag the `.exe`. See
the [v1.0.0 notes](v1.0.0.md#known-gaps) for why, and what would fix it.

## Known gaps

Unchanged from 1.0.0 apart from the UI:

- The model-facing phases have been run live once, by the maintainer, but the evidence is not
  yet in the repository — no recorded cassettes, no measured cost per phase, no published
  `SELF_COMPLIANCE.md`. Treat their output as unreviewed and check every citation.
- Unsigned binaries.
- Two more fixture repositories are wanted.
